# Bake-off rubric — how a candidate scores

Applied as a second pass, never by the prompt's author. Two stages: hard gates
(binary, a failure eliminates the candidate), then scored dimensions (0–5,
weighted). Sourced from `creative-generation.md` §1/§4/§5/§7/§10 and
`compliance.md` §6 — this file makes them scoreable, it does not relax them.

## Hard gates — any FAIL eliminates, no matter how good the craft
| Gate | Source | Fail = |
|---|---|---|
| Real man's photo present | compliance §6.1 | out |
| AI watermark / label, garbled text, glitched hands/faces | §4 / §6.2 | out (unless watermark sits in croppable dead space — note it) |
| Anyone could read under 18 | §6.3 | out |
| Negative-list signifier (gown, luxury, cash, kneeling/serving, etc.) | §4 | out |
| Woman as OBJECT of the frame (posed for desire, not speaking/POV) | §1 | out → escalate |

## Scored dimensions — 0–5 each, weighted
| Dimension | Weight | 0 | 5 |
|---|---|---|---|
| Stop-scroll / does it hit | ×2.0 | scrolls past | stops the thumb in-feed |
| Craft / realism (Tinder-level polish) | ×2.0 | obviously AI-cheap | indistinguishable from a real shot |
| Brand-fit register | ×1.5 | swipe-app party energy | dignified continuation, riteangle voice |
| Palette differentiation | ×1.0 | dark, reads like a Tinder ad | cream/warm, different in-feed before a word |
| Type-safe space | ×1.0 | no room for the hook | clean top-third + bottom band |

**Weighted total /37.5.** Advance the top candidate (or top 2 if close) to the
type pass, then the finished-asset gate in `creative-generation.md` §10. Record the
score and one-line why per candidate in the round ledger.
