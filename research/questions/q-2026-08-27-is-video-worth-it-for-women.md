## Question

Is video worth the code change for women's creative, when creative-style.md says the strongest women's threads read as stills and are hard to convey in six seconds?

## Why it matters

Video is the operator's least-friction named alternative, but rules/creative-style.md:109 already argues against it for exactly this audience: the ordered-shortlist and AI-vetting threads are described as reading beautifully as a still and hard to convey in six seconds of Snap. If that holds, the format axis is the wrong axis to spend the first code change on and carousel — which keeps the still — is the better candidate. If it does not hold, it needs a thread written for motion rather than a still animated.
