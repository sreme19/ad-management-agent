## Claim

Google Flow's model tier is selectable per generation from the prompt box, Veo 3.1 Quality is available, and Omni is feature-limited rather than merely lower quality

## Evidence

- (2026-08-28) (2026-08-28) Kevin Stratvert Flow walkthrough, demonstrating the platform's own UI, no affiliate or product sold. A model selector sits in the prompt box - a second, per-generation control distinct from the Agent-settings dropdown found earlier the same day (lrn-2026-08-28-google-flow-s-output-aspect). Choosing 'frames' mode and then a start AND end frame requires switching off Omni: 'To select both a start frame and an end frame, we need to switch the model to Veo... let's go with Veo 3.1 - Quality. Omni doesn't currently support an end frame.' Two consequences. (1) Veo 3.1 Quality is available and selectable, so round 4's craft score of 2.5/5 in creatives/moveon-swagger-video/qa.md - explicitly attributed to the Omni 1.1 Flash tier rather than to the prompt or format - was bounded by a setting nobody had looked at. (2) Omni is feature-limited, not just grainy: the start/end-frame control, which is rung 2 of the control ladder in note-2026-08-28-two-ai-video-tutorials, is unavailable on it entirely. NOT known: Veo 3.1 Quality's credit cost. Round 4 on Omni cost 10 credits; the Veo figure must be read off the confirmation dialog before committing, since rules/budget.md's envelope is Rs 9,400/month for the whole generation stack.
