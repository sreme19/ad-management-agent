## Claim

OpenAI Sora is discontinued and its API sunsets on 24 September 2026, so it is not a candidate medium

## Evidence

- (2026-08-28) OpenAI deprecations page (https://developers.openai.com/api/docs/deprecations), read 28 Aug 2026, lists sora-2, sora-2-pro, sora-2-2025-10-06, sora-2-2025-12-08, sora-2-pro-2025-10-06 and the Videos API for shutdown on 24 Sep 2026 with no replacement model listed. OpenAI Help Center carries a 'What to know about the Sora discontinuation' article; discontinuation was announced 24 Mar 2026 and the consumer app and web product shut down 26 Apr 2026. TechCrunch (24 Mar 2026) reports the cause as roughly $1M/day to operate against ~$2.1M lifetime in-app revenue. Sora was never launched in India. Practical consequence: any guide, comparison or recommendation naming Sora as a current option is stale, and the same check killed a second stale assumption - Google's frontier video line moved to Gemini Omni, with gemini-omni-1.1-flash reaching GA 27 Aug 2026 per Google's own API changelog, so 'Veo 4' (asserted by several SEO blogs) does not exist.
